이재준(Jaejun Lee)의 한 페이지 포트폴리오입니다. `index.html` 하나로 동작하며 빌드 과정이 없습니다.

- `assets/`: 프로필, 비엔날레 현장 사진(이재준 촬영), 오버제로 화면·식당 사진(팀 발표 자료, 2022)
- `jaejun-lee-cv.pdf`: 같은 아이덴티티의 1쪽 이력서 · `og.png`: 공유 미리보기 이미지
