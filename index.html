A · 과제
미디어 파사드로 거리에서 브랜드 존재감을 만들되, 실제로 지을 수 있어야 했습니다.

입면 시스템 대안 비교, 접합부·소재 검토, 기술 리포트 작성. 글로벌 설계팀과 영어로 협업했습니다.

D · 결과
2025년 8월 개장, iF 디자인 어워드 2026 건축 부문 수상(LG전자 발표).

제4회 서울도시건축비엔날레 게스트시티전

34개 도시의 전시를 하나의 관람 흐름으로

개 도시가 참여한 전시의
배치·동선·설치 조율

비엔날레 전체 관람객 92만 명 (서울시 발표 ↗). 게스트시티전만의 관람객 수는 아닙니다.

A · 과제
총감독의 전시 흐름과 통일된 조립식 전시대 안에서, 작가마다 다른 요구를 함께 살려야 했습니다.
B · 내 역할
작가들과 배치·동선·설치를 조율하고, 큐레토리얼 콘텐츠를 번역했습니다.
C · 판단
개별 요청을 그대로 받는 안도, 전체 흐름만 앞세우는 안도 택하지 않았습니다. 관람객이 작품을 만나는 순서를 기준으로 우선순위를 정하고, 정해진 구조 안에서 작품의 성격이 드러나게 배치했습니다.
D · 결과
2023년 9–10월, 계획한 흐름대로 개막하고 운영되었습니다.

오버제로 — 주문 앱 ‘리빗’

‘잘 보여주는 화면’에서 ‘주문을 끝내게 하는 화면’으로

명의 점주 인터뷰에서
시작한 주문 흐름

2022년 5–7월 · 점주 인터뷰 25명, MVP 3차, 안암 식당 4곳 제휴 (팀 발표 자료 기준)

A · 과제
사전 주문과 매장 QR 결제를 잇는 앱. 정보는 충분했지만 다음 행동이 선명하지 않았습니다.
B · 내 역할
공동대표로 서비스 기획과 UI/UX를 맡아, 주문 시나리오를 직접 반복해 따라갔습니다.
C · 판단
기능을 빠짐없이 보여주는 화면 대신, 주문을 끝내게 하는 화면을 택했습니다. 긴 탐색과 잘게 나눈 카테고리가 결제 전 이탈을 부른다고 봤기 때문입니다.
D · 결과
탐색 → 옵션 → 장바구니 → 결제, 4단계로 정리한 MVP를 세 차례 시험하고 안암 식당 4곳과 제휴했습니다.

소개

ABOUT — HOW I WORK

건축을 전공하고 파사드 컨설턴트로 일하며, LG전자와 현대자동차의 브랜드 공간이 실제로 지어지는 과정을 가까이에서 봤습니다. 그때 확인한 것은 하나입니다. 공간의 완성도는 형태보다, 고객이 무엇을 보고 어떻게 움직이며 브랜드를 이해하는지에서 결정된다는 것.

2026년 제일기획에 입사해 BX 부문에서 공간기획을 맡고 있습니다. 전시, 팝업, 플래그십처럼 브랜드가 사람을 직접 만나는 공간에서, 조건이 달라도 브랜드 전략의 핵심이 흔들리지 않게 구현하는 기준을 만드는 것이 목표입니다.

30여 개국이 모인 기술회의 통역과 글로벌 설계팀 협업으로, 영어로 일하는 데 익숙합니다.
